## What Is Canvas Live 3D?

This project packages a 3D experience for the web, with the HTML canvas element acting as the drawing and presentation layer. Anyone who wants to try out or publish a compact three-dimensional interface can do so by loading it in a current browser -- no installation step beyond that.

Everything stays anchored in the browser and the canvas API, which makes the project a handy sandbox for experimenting with 3D scenes written in plain HTML. Because the whole thing ships as a small web project, it is straightforward to review, host on your own server, or fold into an HTML workflow you already maintain.

## Getting Started

Pull down the repository first:

```bash
git clone https://github.com/martinreed57/canvas-live-3d-2026.git
cd REPO
```

Once cloned, load the main HTML file in a current browser. Should the browser block resources loaded from disk, run the folder through a minimal HTTP server instead:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000/
```
